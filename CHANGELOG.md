# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-08-18

### Added

- Streamlit web interface for Codeforces handles
- Public Codeforces rating-history integration
- Logarithmic regression trend model
- Interactive Plotly chart with explicit projection boundary
- Rating and model summary metrics
- Friendly handle validation and API/network errors
- Recent rated-contest table
- Automated pytest test suite
- GitHub Actions continuous integration
- Streamlit theme configuration
- Project documentation and MIT license
